# Oki for Mac

Download **Oki-mac-arm64.dmg** from the [latest release](https://github.com/OkiAI/oki-desktop-releases/releases/latest) and open it. In the window that appears, drag Oki onto the Applications folder, then open Oki from Applications. If macOS says it cannot verify Oki, open System Settings > Privacy & Security and click Open Anyway (once). Installed copies update themselves.

Windows: download **OkiSetup.exe** from the same release and open it.
